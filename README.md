# README

This project contains a premium robotics and mechatronics portfolio for Fidèle Nacoulma.

## Features
- Futuristic dark UI with glassmorphism and neon accents
- Responsive portfolio layout for desktop and mobile
- Project filtering and individual project detail pages
- Experience, education, certifications, gallery, and contact sections
- Placeholder-driven content for missing CV, projects, certificates, and media

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
